# pyTM
티처블 머신에서 만든 모델을 파이썬으로 SW로 구현함.
가상환경은
```
conda create -n tm006 python=3.7
conda activate tm006
```
가상환경에서 패키지 인스톨은 
```
pip install -r requirements.txt
```
을 입력 합니다. 
실행 명령은 
```
python app.py
```
